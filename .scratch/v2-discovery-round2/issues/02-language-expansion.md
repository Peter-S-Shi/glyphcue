# 分阶段语言能力与下一批优先语言

Type: research
Status: resolved
Assignee: round2-languages
Blocked by: none

## Question

如何按 ASR、翻译方向、TTS 声线、对齐及文本渲染准确声明语言能力；在 EN/ZH/FR 锚点外，下一研究优先级及新增工程成本是什么？

## Answer

按阶段、方向、声线、locale、运行环境及证据级别声明能力；EN/ZH/FR 是评价锚点而非三语类型上限。建议 ES/IT/pt-BR 首批扩展研究、DE 配音条件门槛，JA/KO 第二批，AR/HI/TH 专项。Qwen ASR/aligner/TTS 的覆盖交集不一致；许可和声音来源按精确资产核对。已完成文档研究，模型质量与 Windows 行为仍待实验。
