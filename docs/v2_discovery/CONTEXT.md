# GlyphCue V2 Discovery 词汇表

本词汇表描述 V2 建议的产品语义，供设计阶段确认。它不改写 V1 领域术语。

## Language

**源媒体（Source Media）**：用户用于转录或本地化的视频/音频素材。音轨选择和处理范围属于这份素材的处理上下文。

**原始转录（ASR Result）**：语音识别产生的原始文字及估计时间信息，尚未经人工确认。它与校正后的源文并存。
_Avoid_: 最终字幕、正确答案

**源转录修订（Source Transcript Revision）**：用户当前认可或正在校正的源语言文本及其音频定位关系。

**字幕段（Subtitle Cue）**：在一个显示区间内呈现的一组文本。分段由可读性和编辑需求决定，不必等于一次识别输出的 segment。

**目标文本修订（Target Text Revision）**：关联到源转录修订的某一种目标语言文本，包含机器译文或人工编辑。

**双语字幕（Bilingual Subtitles）**：同一播放区间同时显示源语言和目标语言文本的字幕表达。

**配音稿（Dubbing Script）**：准备用于合成或录制语音的目标语言文本，可为自然朗读调整措辞，并与目标字幕保持可追溯关系。

**配音段（Dubbing Segment）**：一个可独立生成、试听和替换的语音单元，具有实际时长与媒体中的放置位置，可关联多个字幕段。

**声线（Voice）**：生成配音所选的声音表现。标准合成声线与克隆某个现实人物的声音是不同能力。

**强制对齐（Forced Alignment）**：将已知文字与实际说出这些文字的音频对齐以估计边界；不等同于翻译，也不确定谁在说话。

**衍生产物（Derived Artifact）**：由特定输入修订生成的译文、音频或渲染媒体；输入变化后可能需要更新。

**烧录字幕（Burned-in Subtitles）**：文字已写入视频画面的输出，播放时无法单独关闭。
_Avoid_: 与软字幕混用的“嵌入字幕”

**软字幕（Soft Subtitles）**：作为独立文件或媒体中的字幕轨存在的文字，播放器支持时可切换或关闭。
