# GlyphCue V2 第二轮词汇表

供绿地产品设计讨论使用；不受 V1 对象结构约束。

## Language

**项目**：一份可重新打开、校正和导出的媒体本地化工作。

**源媒体**：作为工作依据的某一版视频或音频内容；当前位置可以变化。

**音轨选择**：用户决定要识别的媒体音轨、通道及时间范围。

**ASR 证据**：本地识别器产生的原始文字与估计时间信息，尚未被人工修订替代。

**源转录**：用户编辑的源语言文字及其与原音的定位关系。

**修订**：同一份内容在某一时刻的确定版本。

**字幕段**：为播放显示而安排在一个时间区间内的文字单位。

**翻译单位**：一段需要按指定源/目标语言处理的语义内容，可以关联多条字幕。

**配音稿**：为自然朗读准备的文字，与屏幕译文有关联但可以有意不同。

**声线**：许可明确的预设合成声音；不是现实人物的身份。

**音频候选（Take）**：基于某版配音稿和声线生成的一次语音结果。

**放置**：音频候选在源视频时间线上的位置及经确认的时长调整。

**锁定**：禁止生成过程覆盖选定的人工成果，仍允许其被标记为依据已变化。

**过期**：结果所依据的输入已有新修订，需要核对是否继续使用。

**中断**：执行因退出或崩溃等原因没有得到确定的最终结果。

**阶段能力**：某种语言、方向或声线，在特定处理阶段已经具备的可用范围。

**烧录字幕**：已写入画面的文字，播放时不能单独关闭。

**软字幕**：独立文件或媒体字幕轨中的文字，播放器支持时可以关闭或切换。
