## 当前结论

推荐的产品闭环是：本地媒体 → 本地 ASR → 带来源的可编辑源文字 → 可选的有向双语翻译 → 可选的单旁白预设声线配音 → 字幕/音频/烧录成片导出。外部翻译和 TTS 可以作为用户主动选择的 BYOK 能力；ASR 不得静默上传或云回退。

EN、ZH、FR 是首轮验收锚点，不是永久语言上限。语言支持必须按阶段、方向、声线、对齐、字体和导出证据拆开声明。V1 不承担迁移和 UI 兼容义务；可复用的只有经过独立审查的工具、测试和发行经验。

## 状态与下一步

研究文档已完成，产品范围冻结仍待用户评审。当前没有模型下载、性能结论、UI 原型或发行批准。下一步应先评审设计范围契约，再按产品门选择最小语言、运行时和壳实验；实验结果不能反向扩大本轮范围。

本轮日期为 2026-10-03。官方网页、源码和模型卡可能变化；实施前必须锁定精确 revision、哈希、依赖、许可证和硬件验证记录。
