# V2 最小决策实验

本轮不下载模型、不运行推理、不制作 UI 原型。下列实验只覆盖当前证据不能回答的门。

| 优先级 | 实验 | 最小输入与记录 | 决策输出 |
|---|---|---|---|
| 1 | 语言锚点闭环 | 同一份获授权 EN/ZH/FR 短材料；六个翻译方向；固定本地 ASR、翻译、预设声线和字体 | 每方向错误、修订时间、cue 边界、溢出、TTS 时长、离线状态；形成 PG-07 候选 |
| 2 | runtime 对照 | whisper.cpp CPU/Vulkan 与 CT2 CPU/CUDA（必要时 AMD ROCm smoke）使用同一音频和输出协议；Qwen ASR+ForcedAligner 作为质量挑战者 | 质量、吞吐、峰值内存、安装体积、取消/恢复、许可证；不从榜单推断赢家 |
| 3 | 壳与编辑切片 | Qt Quick 与 Tauri 各做同一份 stub 数据：长 cue 列表、中文输入、法语重音、时间拖动、撤销、键盘焦点 | 编辑成本、可访问性、IPC 和打包故障；决定 PG-05 候选 |
| 4 | 媒体与导出 | VFR、长 GOP、多音轨、Unicode 路径的授权样本；代理、seek、双语 ASS、烧录短段 | 预览时间映射、音画同步、字体覆盖、FFmpeg build 与许可清单 |
| 5 | 资源和恢复 | 无开发环境的干净 Windows；模拟断网、损坏下载、OOM、关闭窗口和孤儿产物 | PG-06/09 的最低行为和恢复条件 |
| 6 | 扩展文字 | 不用模型的 ES/IT/pt-BR、JA/KO、未来 RTL 合成文本 | 字素、断行、Bidi、搜索、字体和字幕导出是否需要原型；不证明 ASR/TTS 支持 |

所有实验固定 revision、配置、数据集哈希和硬件；记录“未测”而非补写通过。框架实验不应先下载完整模型，模型实验不应把 UI 壳混入质量评分。实验结果进入产品门记录，再决定具体实现。
